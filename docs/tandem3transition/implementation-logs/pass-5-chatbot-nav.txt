## SUMMARY

Pass 5 consolidates the operator-facing navigation from nine areas down to
four top-level sections (Home, Conversations, Chatbot, Account) and introduces
the /chatbot page as a unified tabbed view of all chatbot configuration.

Pass 5 builds on partial work from the WIP commit
(wip(tandem3-pass-5): partial chatbot page and nav restructure) and completes:
  1. /chatbot page with four tabs: Knowledge | Handoff | Behavior | Appearance
  2. ConsoleTopbar reduced to four nav items
  3. BusinessSubNav removed from layout rendering
  4. Redirects for all old routes pointing to new destinations
  5. /account expanded to absorb business identity and integrations role

Key design decisions:
  - /chatbot embeds existing sub-pages (knowledge, handoff, intents, widget) as
    tab content. This is a transitional approach: the sub-pages remain accessible
    directly via redirects and continue to function as full editors.
  - The ConsoleSidebar write-path principle is preserved; forms in sub-pages
    remain functional during the transition.
  - /account is read-focused: business identity and integrations are displayed
    as structured data from the mock store; editing flows through the AI sidebar.
  - BusinessSubNav (the old 7-tab horizontal strip) is no longer imported or
    rendered anywhere in the console layout.

## KNOWN ISSUES

1. Sub-page h1 duplication: The knowledge sub-page renders <h1>Knowledge</h1>
   and the intents sub-page renders <h1>Assistant</h1>. When these are embedded
   inside /chatbot tabs, the operator sees both the "Chatbot" page heading and
   the sub-page section heading. This is a visual redundancy, not a functional
   issue. It will be resolved when sub-pages are rebuilt as read-only tab
   panels (a future cleanup pass).

2. BusinessSubNav.tsx file remains: The component file is not deleted; old
   routes it linked to still exist as redirect sources. Cleanup (deleting
   BusinessSubNav.tsx) is deferred to a future pass.

3. Pre-existing lint errors in conversations/page.tsx, intents/page.tsx,
   knowledge/page.tsx, and layout.tsx are not caused by Pass 5 and are
   unchanged from Pass 4.
