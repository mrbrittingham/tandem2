TANDEM 2.0 VS CODE AGENT INSTRUCTIONS (CHATGPT 4.1)

These instructions inform the VS Code agent how to behave when editing the Tandem 2.0 project.

SECTION 1 — PROJECT DESCRIPTION

You are assisting in the development of Tandem 2.0, a multi-restaurant AI chatbot platform built as a monorepo. The platform uses:

Next.js App Router

Supabase Postgres

A reusable chat widget (UI-kit)

A script embed package

A dashboard for restaurant management

The project is designed to run entirely inside a Docker Devcontainer on WSL2 Linux.

SECTION 2 — MONOREPO STRUCTURE

tandem/
apps/
chatbot/ Next.js public site and demo at /tandem
dashboard/ Next.js admin portal
packages/
ui-kit/ Chat widget library
shared/ Types, schemas, utilities
embed/ External website embed script
public/ Restaurant-uploaded assets
supabase/
docs/
.devcontainer/

All code must fit correctly within this structure.

SECTION 3 — BACKEND REQUIREMENTS

Backend is exclusively Next.js API Routes located in:

apps/chatbot/app/api/*

Do not create or suggest:

Express servers

CORS configurations

Multiple backend runtimes

Standalone Node servers

SECTION 4 — UI-KIT BEHAVIOR

UI-kit must:

use React + TypeScript

export ChatWidget, FloatingTrigger, header, bubbles, input, typing indicator

accept theme objects

match the Figma design direction

use modular, maintainable components

avoid duplicate JS/TS code

SECTION 5 — THEME ENGINE REQUIREMENTS

Themes are loaded from Supabase.
Themes are dynamic per restaurant and control:

colors

fonts

icons

gradients

radii

UI styles

The agent should ensure the UI-kit uses theme tokens consistently.

SECTION 6 — MODIFIER AND WORKFLOW SYSTEM

Restaurants may enable various modifiers such as:

wine pairing

gluten-free

vegetarian

allergy support

spicy levels

The database includes appropriate tables for modifiers.
The backend API dynamically activates different OpenAI tools depending on which modifiers are active.

Reservation workflows vary per restaurant (manual, external link, Toast, Resy, custom).

SECTION 7 — DEMO PAGE

apps/chatbot/app/tandem/page.tsx is a single, static demo page for Windmill Creek.
Background is a screenshot of their site.
All real data is loaded from Supabase.

SECTION 8 — SUPABASE USAGE

Use Supabase for:

menus

menu_items

FAQs

modifiers

reservation_settings

restaurant_settings

themes

Do not generate database logic outside of the schema or migration flow.

SECTION 9 — AGENT OPERATIONAL RULES

The VS Code agent should:

follow the Tandem 2.0 architecture

generate code only within appropriate folders

avoid destructive changes without confirmation

provide small, incremental changes

ask for confirmation before creating or modifying many files

respect the WSL2 + Devcontainer setup

Avoid performing:

automated terminal restarts

node/port killing

server restarts

If a restart is required, prompt Mike to perform it manually.

SECTION 10 — COMMUNICATION STYLE

Provide step-by-step instructions when running commands

Use clear, concise explanations

Keep tone casual, direct, and procedural

Prefer small, self-contained modifications
